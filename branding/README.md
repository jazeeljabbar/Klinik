# KliniK Brand Guidelines

This directory contains the shared source of truth for the KliniK brand system across both Web and React Native applications.

## Identity
- **Product name:** KliniK
- **Positioning:** Clinical precision. Human warmth.
- **Tone:** Empathetic authority, calm, clinically credible, never alarmist.
- **Typography:** Inter

## Color Palette
Refer to `colors.json` for precise hex values.
- Primary buttons: Navy Primary with white text
- Secondary buttons: White background with Navy outline
- Calls to Action (CTAs): Coral Accent
- Severity indicators: Mint Success (Mild/Success), Amber/Yellow (Moderate), Coral Accent (Severe), Dark Red (Very Severe).

## Spacing & Components
- 8px spacing grid
- 12px-16px border radius on cards and buttons

## Terminology
Never use: "diagnosis", "medical advice"
Use instead: "AI-powered assessment", "educational purposes", "skin analysis"
